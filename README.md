# Kings-Limpeza
PWA para loja de produtos de limpeza
Frontend e backend: Next.js no mesmo projeto.
Banco e autenticação: Supabase/PostgreSQL.
API: rotas do próprio Next.js ou REST simples.
Hospedagem: Vercel ou Cloudflare no plano inicial.
PWA básica: cache de imagens, catálogo e carrinho.
Imagens: storage do Supabase ou Cloudflare R2.
ERP: integração somente quando o volume justificar.
